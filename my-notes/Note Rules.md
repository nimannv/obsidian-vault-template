## Note title
Don't be strict about it. title should be unique, but it doesn't mean that the note is identified only by its title.
Actually, I believe the note's identity comes mainly from these two:
1. Note content! (obviously)
2. Note connections.
The title tries to represent these 2, and it tries. Sometimes it does it well, sometimes not. I can make it better later when there is a better title
