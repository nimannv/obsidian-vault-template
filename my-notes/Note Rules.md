> [!caution]
> Mission number one is **KEEP IT SIMPLE**; each rule should simplify the system, not make it more complex
## Note Title
Don't be strict about it. title should be unique, but it doesn't mean that the note is identified only by its title.
Actually, I believe the real note's identity comes from these two:
1. Note content! (obviously)
2. Note connections.
The title tries to represent these 2(and it tries!). Sometimes it does it well, sometimes not. I can always change the title later when there is a better title. So take it easy...

## Note Properties
- `tag`: the only way to categorize my notes. [[Note Tags]]
- `maturity`: [[Note Maturity]].
- `status`: to use in TODO base [[Note Status]].
- `description`: anything that the title of the note can't tell.
## Note Body
**NO RULE!!!** Only for facilitating; there are some templates that can make writing faster:
- **Meeting**: for meetings, use this template.
- **Person**: to create the body of the note about a person.
- **TODO**: to add a TODO section to a note.
